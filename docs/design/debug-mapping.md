# 调试映射（#line）

依据 ADR-0004。行为由 tests/Nyxel.Compiler.Tests/RoslynLineMappingTests.cs 固定下来（2026-10-02，Roslyn 5.9.0）。M2 的降级阶段生成 C# 时必须遵守本文的规则。

## 指令形式

```
#line (起始行, 起始列) - (结束行, 结束列) 列偏移 "文件路径"
```

- 行和列都从 1 开始，**结束列包含在内**（Roslyn 内部会加 1）。C# 规范的措辞读起来像不包含，以实测为准。例：`let share = hp / parts` 占第 9 到 30 列，写成 `(5, 9) - (5, 30)`。
- **列偏移**是指令下一行开头那段“生成的前缀”的长度：
  - 从前缀里开始的序列点或诊断，映射到整个指令跨度；
  - 前缀之后的文本从起始列开始逐列对应；
  - 第二行起保持生成的列。
- 不写列偏移时前缀长度为 0，生成代码的缩进会叠加到每个映射列上（实测 Nyxel 第 9 列变成了第 21 列）。列偏移至少为 1。
- `#line hidden` 用于没有 Nyxel 对应的脚手架代码：序列点是隐藏的（行号 0xFEEFEE），调试器单步时跳过。

## 生成规则

1. **一条映射语句占一行，列偏移等于这一行第一个字符的列**（从 1 开始）。这样语句从前缀里开始，它的序列点正好是 Nyxel 语句的跨度。
2. 同一行里有自己序列点的结构（lambda 体、`for` 头部各段）拆到单独的行，各带指令。
3. 生成的语句跨多行时，要么保持 Nyxel 的行结构，要么拆开分别加指令。
4. 生成器必须知道每条映射语句的生成列。最直接的做法是带列跟踪的缩进文本写出器生成 C# 文本，再 `CSharpSyntaxTree.ParseText`；SyntaxFactory 也能做，但列不直观。M2 设计降级时定。
5. 函数的 `{` 和 `}` 也映射，这样断点可以停在函数入口和出口。
6. **路径写绝对路径**。路径会原样写进 PDB、异常堆栈和诊断：不做规范化，反斜杠不是转义，路径里不能有 `"`。不要给编译选项设 `SourceFileResolver`（`csc` 就设了），否则相对路径会按生成文件所在目录解析。

## 实测行为

- **PDB 序列点**：从 1 开始，结束列不包含。指令 `(5, 9) - (5, 30)` 在 PDB 里是 `(5,9)-(5,31)`。
- **字段初始化器**在构造函数里执行，但保留字段那一行的映射。
- **异常堆栈**：程序集和 PDB 一起从流加载到可卸载的 AssemblyLoadContext 时，堆栈显示 `in Slime.nyxel:line 5`，帧的行列是 5 和 9。磁盘上不需要 .pdb 文件。
- **隐藏代码里抛出的异常**归到它之前最近的可见序列点。编译器插入的检查（比如参数检查）抛异常时，堆栈指向函数开头的 `{`。
- **Roslyn 诊断**：`GetMappedLineSpan()` 从 0 开始、结束不包含，`HasMappedPath` 为 true。从前缀里开始的错误映射到整条语句；前缀之后开始的错误，行准确、列是近似的。
- **PDB 里文档的语言标记是 C#**：调试器的监视窗口和即时窗口按 C# 语法求值表达式，不是 Nyxel。

## 校验和与嵌入源码

- 既不嵌入源码、也不写 `#pragma checksum` 时，PDB 里 .nyxel 文档没有校验和，调试器发现不了源码已经改过。
- **嵌入源码**：`EmbeddedText.FromBytes(路径, 文件原始字节, SourceHashAlgorithm.Sha256)` 传给 `Emit(..., embeddedTexts:)`。
  - 路径必须和 `#line` 里的字符串完全一致，否则 PDB 里会多出一个文档。
  - 用文件的原始字节：用 `Encoding.UTF8` 构造 SourceText 会把文件里没有的 BOM 也算进校验和。
  - 嵌入同时会写入 SHA-256 校验和；超过 200 字节的文件 Roslyn 会压缩。
- **只要校验和**：`#pragma checksum "路径" "{8829d00f-11b8-4213-878b-770e8597ac16}" "SHA-256 十六进制"`（Razor 的做法）。
- 计划（M2 定）：开发和热重载构建默认嵌入源码，发布构建可选；任何情况下都记录 SHA-256 校验和。

## Roslyn 诊断兜底

- 包装成内部错误时用 `GetMessage(CultureInfo.InvariantCulture)`：Roslyn 的消息跟随系统 UI 语言（本机是中文）。

## 还没验证

- 真实调试器（VSCode 的 C# 调试器、Rider）在 .nyxel 上停断点。扩展已声明 `contributes.breakpoints`；等有能跑的 .nyxel 程序时，作为 M2 验收的一部分手动验证。
- 可卸载 ALC 卸载后确实被回收（测试只调用了 `Unload()`），留给 M4 热重载。
